## Story
RCA-022 Invalid configuration is rejected by the constraint model

Given bundle BND-ANALYTICS-SUITE whose constraint model forbids ADD-PREMIUM-SUPPORT when Tier = Standard
When a quote is placed with Tier = Standard and ADD-PREMIUM-SUPPORT selected
Then the transaction returns a configuration error naming the rule and no quote lines are saved
And with Tier = Enterprise the same selection is accepted

Expected result: invalid → status not 200 or configuration error present, 0 lines; valid → 200 and 3 lines
Data prerequisites: constraint model active on the bundle in DEV
